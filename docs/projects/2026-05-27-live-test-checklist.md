# 라이브 테스트 체크리스트 (사용자 직접 확인 필요)

> 코드+유닛+Codex로는 검증 못 하고 **화면공유·게임플레이로 사용자가 직접 확인**해야 하는 항목 목록.
> 새 기능 만들 때마다 여기 누적. 확인되면 [x] 체크.

## 자기장 검출 (3-상태 수정)
- [ ] **전체맵(안 줌) 정상 검출** — M키로 전체맵 열면 실제 위치에 자기장 원이 그려진다 (우상단 가짜원 없음).
- [ ] **줄어드는 중 페이즈 유지** — 자기장 줄어드는 동안에도 페이즈 갱신되며 검출 유지.
- [ ] **확대(줌인)** — 현재 SIFT 폴백 off(`SIFT_ZONE_ENABLED`). 줌 자기장은 C 재설계 후 재확인.

## 태이고
- [ ] **태이고 명당 표시** — 태이고 맵에서 명당 마커(526개, S/A/B/C)가 화면에 뜬다.
- [ ] (참고) 에란겔 명당 955개 정상 표시.

## D. 종료감지 OCR (이번 구현)
- [ ] **치킨** — 치킨 화면(노란 텍스트)에서 알림·자기장 초기화된다.
- [ ] **사망** — 사망/결과 화면(어두움 + 순위 "#N/99" 텍스트)에서 OCR 확인 후 초기화된다.
- [ ] **어두운 인게임 오판 없음** — 동굴·야간 등 어두운 인게임 화면에서는 초기화 안 된다(OCR 텍스트 없으니).

## (예정) C 줌 / E 유저위치 / 어드민
- [ ] C(줌 arc-only) 구현 후 — 확대 화면에서 자기장 복원.
- [ ] E(유저 실시간 위치) 구현 후 — 미니맵 기반 플레이어 마커.
- [ ] 어드민 페이지(env 비번) — 로그인 + API 테스트 UI.
