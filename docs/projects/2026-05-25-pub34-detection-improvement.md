# PUB-34 검출률 문제 — 발견과 개선 방향

> 2026-05-25. (MAP) chain 중간점검 중 발견한 검출 누락 문제 + 진단 + 개선 방향.
> Linear: PUB-34. 진행 main: `docs/projects/2026-05-25-pub34-map-chain-resume.md`.
> 검증 영상: `GO25rM_CoHo` sec=4230 (TEAMS/16, ALIVE/63, PHASE/1).

## 핵심 발견 — 검출률 ~10%

영상 한 프레임을 720p에 가깝게 확대해 사람이 검증한 결과, 화면에 **16팀 63명이 생존(마커+이름표 표시)**해 있는데 **우리 파이프라인은 6명만 검출**했다. 이 프레임(sec=4230)은 이 영상에서 **마커가 가장 많이 잡힌 단 하나의 프레임**이고, 67개 전체맵 프레임 평균은 **0.7개/프레임**.

즉 **데이터의 ~90%를 놓치고 있다.** 명당이 그래도 나온 건 명당 자리가 여러 영상·프레임에서 반복돼 일부라도 누적된 것일 뿐, 효율이 극히 낮고 검출 편향 위험이 있다.

## 원인 진단 (sec=4230, CPU 추론, GO25rM 360p 원본)

| 설정 | 점 마커(player+vehicle+air) | 이름박스(namebox) |
|---|---|---|
| 1x (360p, 현재 chain) | 2 | 9 |
| 2x 업스케일 imgsz1280 | 10 | **18** |
| 3x 업스케일 imgsz1280 | 9 | 18 |

### 원인 1 — 저해상도
chain이 `best[height<=480]`로 받아 **360~480p로 분석**. 전체맵에서 선수 마커는 몇 px라 YOLO가 못 본다. 2~3x 업스케일만으로 검출 2~3배. **원본 720p+면 더 클 것**(cubic 업스케일은 가짜 정보라 한계).

### 원인 2 — 이름박스 미사용 (가장 큰 손실)
모든 살아있는 선수엔 **이름박스가 100% 부착**되는데(영상 진실), YOLO는 작은 점보다 **큰 이름박스를 2~3배 잘 잡는다**. 그런데 `full_pipeline.py`는 `if c == 1: continue`로 **이름박스를 버리고** 점만 쓴다. 가장 잘 잡히는 신호를 안 쓰는 셈.

### 함정 — 추론 imgsz는 학습값(1280)과 일치해야
진단 중 `imgsz=1920`으로 추론하니 검출이 9→1로 붕괴. 모델이 imgsz=1280으로 학습돼서다. **추론도 1280 고정**. 업스케일은 입력 프레임을 cv2로 키우되 `predict(imgsz=1280)` 유지.

## 이름박스 → 동그라미(프로 위치) 오프셋

`synth_gen.py` `draw_name_box` (우리가 합성 시 직접 정한 규칙 = 정답):
```python
by = my + MARKER_RADIUS + 4   # 이름박스 윗변 = 동그라미중심 + 14px
bx = mx - text_w // 2         # 이름박스 가로중심 = 동그라미 x
```
- **동그라미 중심 = 이름박스 윗변에서 위로 14px** (MARKER_RADIUS 10 + 간격 4)
- **가로는 이름박스 한가운데와 일치**
- 단 마커 반지름 10px 기준 — 실제 영상 마커 크기에 비례 조정 필요.

→ 이름박스를 검출 단위로 쓰고, 박스 윗변 중심에서 14px(스케일) 위를 선수 좌표로 변환하면 검출률을 크게 올릴 수 있다.

## 부수 발견

- **중복 검출**: 같은 픽셀을 airplane/vehicle로 2번 잡음(둘 다 저conf). 명당엔 static만 쓰여 영향 없음.
- **combiner 오염**: weekly_test 단일영상이 클러스터 입력 61% 차지 → **정품화 완료**(MAP만 사용). 상세 `2026-05-25-decision-pub34-data-midcheck.html`.
- **좌표 정렬은 정확**: SIFT reprojection 0.30~0.31px (≈2m). 잡은 것의 위치는 믿을 만함.

## 개선 방향 (사용자 합의: 이름박스 + 고화질 동시)

1. **이름박스를 검출 단위로** — 점 마커와 union, 이름박스는 윗변중심-14px(스케일)를 좌표로.
2. **고해상도 추론** — 원본 720p/1080p 확보(현재 봇차단). imgsz는 1280 고정, 입력 프레임만 키움.
3. **재분석** — 개선 후 기존 결과(저검출)는 폐기/재생성. chain 재설계.
