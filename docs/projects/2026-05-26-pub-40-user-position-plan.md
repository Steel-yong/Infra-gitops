# PUB-40 — 유저 실시간 위치 표시 (미니맵, 고전 CV 먼저)

> Linear: PUB-40. 작성 2026-05-26. 역할: Claude 구현, Codex 검수. 결정 목업: `docs/resources/mockups/2026-05-26-decision-user-position.html`.

## 배경 / 목표
플레이 중 우리 UI(Leaflet 맵)에 **플레이어 자기 위치를 실시간 표시**한다. 기존엔 자기장·프로 명당만 표시했고, 유저 본인 위치는 없다(신규 기능).

## 결정 (사용자 승인)
- **소스 = 미니맵(실시간).** 전체맵은 열 때만 보여 "실시간" 요구에 안 맞음.
- **접근 = 고전 CV 먼저.** PUB-39의 AKAZE 호모그래피(화면→게임좌표 0~1)를 재활용. ML(학습)은 폴백.

## 핵심 아이디어
1. 캡처 프레임에서 **미니맵 영역 크롭**(우하단 고정 위치).
2. 미니맵을 erangel/taego 기준맵에 **AKAZE 매칭 → 호모그래피**(미니맵 픽셀 → 게임좌표).
3. **미니맵 중심점 ≈ 플레이어** → 호모그래피로 게임좌표(x,y) 변환.
4. 미니맵 흰 **화살표 방향** 검출 → heading(방향) 추출.
5. WebSocket으로 프론트 전송 → 지도에 방향 마커 표시.

## 리스크 (선검증 필요)
미니맵이 좁아 AKAZE 특징점이 부족하면 호모그래피 실패 가능. → **PoC 1건 먼저**(`.claude/images` 스크린샷 미니맵 영역, inlier 임계 통과 여부).

## 단계 (각 검증 포함)
1. PoC — 미니맵 크롭에 AKAZE 호모그래피 → 검증: inlier 임계 통과하나. 실패 시 ML 분기 결정.
2. `capture`에 `detectPlayer(base64)` → `PlayerPosition{x,y,heading}` → 검증: 유닛 테스트(합성+실제 픽스처).
3. `shared`에 `PlayerPosition` 타입 → 검증: 빌드 통과.
4. WebSocket 이벤트 전송 → 검증: 프론트 수신 확인.
5. 프론트 `PlayerMarker`(`[1-y, x]` 변환 + 방향 회전) → 검증: 지도에 마커·방향.

## 비범위
- 전체맵 기반 위치(열 때만) — 이번 아님.
- ML 학습 — 폴백, 이번 아님.

## 완료 기준
- 플레이 중 미니맵에서 플레이어 위치가 지도에 실시간 표시(방향 포함).
- PoC inlier 검증 통과 + 유닛 테스트 + Codex 검수 통과.
