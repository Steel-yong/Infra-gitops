# PUB-31 — 위치 추천 UI 우측 사이드바 분리 — Context Notes

> 2026-05-18 작업 중 내린 결정과 이유.

## 1. B안 (최소 변경) 채택

### 결정

3가지 옵션(A: 3분할 완전 재구성 / B: LocationPanel만 우측으로 / C: 캡처 PiP) 중 **B 채택**.

### 이유

- 이번 작업의 본질은 "위치 추천 시선 분리"이지 "전체 레이아웃 재설계"가 아님.
- OCR 디버깅용 캡처 미리보기는 자기장 검출 튜닝(PUB-30 §7.1 맵 확대)이 끝날 때까지 항상 크게 보이는 게 안전.
- 변경 폭이 작아 PUB-30에서 막 안정화된 자기장 시스템에 회귀 위험 적음.
- B는 A의 대안이 아니라 **A로 가는 디딤돌**. 7.1 완료 후 별도 이슈에서 A/C로 진화 가능.

### 적용

- `apps/frontend/src/app/page.module.css` — `.rightSidebar` 추가.
- `apps/frontend/src/app/page.tsx` — 좌측 사이드바 마지막 sideSection 제거 + 우측 aside 신설.
- mockup: `docs/resources/mockups/2026-05-18-decision-우측-사이드바-레이아웃.html`

## 2. LocationPanel 컴포넌트 자체는 손대지 않음

### 결정

`LocationPanel.tsx`와 `LocationPanel.module.css`는 수정 없음. 감싸는 컨테이너(`<div className={styles.sideSection}>`)만 좌측에서 우측으로 옮긴다.

### 이유

- 컴포넌트 내부 로직(거리 계산, 정렬, tier별 표시)은 위치와 무관.
- 컴포넌트 자체를 건드리면 회귀 위험만 늘어남.
- 컴포넌트 props 변경 없음 → 단위 테스트 영향 없음.

### 적용

- `page.tsx`의 JSX 트리 구조만 변경.
- `page.module.css`에 `.rightSidebar` 한 블록만 추가.

## 3. 좌측 사이드바 빈 공간 처리

### 상황

LocationPanel 제거 후 좌측 사이드바는 "맵 선택 / TimerPanel / 자기장 알림"만 남는다. 컨텐츠 길이가 짧아져서 아래쪽에 빈 공간 생김.

### 결정

빈 공간을 메우려 하지 않는다. 다크 배경 그대로 둠.

### 이유

- 사이드바는 이미 다크(#13131f) 배경 — 빈 공간이 어색하지 않음.
- 억지로 알림 영역을 `flex: 1`로 늘리면 체크박스 3개가 화면 가득 흩어져서 더 어색.
- 향후 좌측에 새 입력 UI(예: 캡처 품질 설정)를 추가하기 좋은 여백으로 활용 가능.
