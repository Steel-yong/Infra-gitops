## 검증 흐름

1. 자율 BEST 57곳에 도시 anchor 기반 한국어 설명 + 격자 라벨 + 방향 부여 → `2026-05-20-pub34-verify-best.html`.
2. 사용자 시각 검증 결과 **마커가 게임 내 실제 명당과 전혀 일치하지 않음** 보고.
3. 27도시 단독 진단 페이지 생성 → `2026-05-20-pub34-diagnose-cities.png`. 27도시 모두 게임 내 실제 위치와 정확히 일치 확인.
4. 결론: **도시 좌표계는 정확하나 자율 분석이 만든 명당 좌표가 부정확하다**.
5. 가장 신뢰성 강한 BEST 3곳(엄격 필터 통과)을 줌인 시각화 → `2026-05-20-pub34-strict-1/2/3.png`. **#2 후보가 바다 위에 찍힌 것** 확인.
6. 사용자 결정: **자율 분석 결과 전량 폐기**.

## 원인 (구조적 결함)

`apps/services/video-analyzer/stream_analyze.py` (PUB-34 워크트리):

- 줌인 미니맵의 **격자 라벨**(예: F7, K3) OCR로 transform 도출.
- OCR 실패율 높음 → **default transform fallback** 빈번 발동.
- fallback 좌표가 한쪽(맵 동쪽 끝 Lipovka/MyltaPower)으로 누적 → 엄격 필터 통과 3곳 모두 동쪽 끝, 1곳 바다 위.
- 3-offset cross-validation은 *시간 안정성*만 검증할 뿐 좌표 *정확성*은 보장 못함.

**검증된 도시 anchor를 안 쓰고 격자 라벨에만 의존한 게 구조적 결함.**
