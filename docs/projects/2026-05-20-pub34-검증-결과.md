## 2026-05-21 — 2차 시도 (SIFT homography) 마커 검출 실패 기록

**시도:** erangel.jpg ↔ 영상 미니맵 SIFT homography (reprojection error 3.79m, 매우 정확). 그 위에 HSV 색깔 픽셀을 Connected Components로 묶고 원형도 필터로 "원만" 추출 시도.

**실패 사유:** PUBG 마커 구조 = **(1) 작은 색깔 원 + (2) 그 아래 둥근 닉네임 라벨 박스 (같은 색)**. 색 픽셀 추출 + 원형도 필터는 **둥근 닉네임 박스의 중심을 마커로 잡음** → 실제 마커 위치보다 박스 중심만큼 어긋남. 사용자 시각 검증 "안 맞는다" 확인.

**다시는 반복하지 말 것:**
- HSV 색깔 픽셀만으로 마커를 판단하지 말 것. 닉네임 박스 = 마커가 아님.
- "원형도 ≥ 0.6 + 작은 area"라는 형태 필터는 둥근 박스도 통과시킴.

**다음 시도 방향 (3차):**
- **diff 기반**: SIFT로 정렬한 base ↔ 영상 픽셀 차이 → 게임 오버레이만 추출 → 그 중 작은 동그란 색 영역.
- 또는 **닉네임 박스 → 박스 상단 위 5~10px** 위치를 마커로.
- 또는 **template matching** — PUBG 마커 한 세트를 템플릿으로 자르고 cv2.matchTemplate.
