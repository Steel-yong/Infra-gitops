## 왜 더 진행 안 하고 멈췄나 (근거)
- 핵심 CV(미니맵 로컬라이제이션) 접근이 미결이고, 승인 접근이 PoC로 깨졌다.
- 결정 전에 하드 CV(템플릿매처)를 만들면, 틀린/실패할 방향에 노력 낭비 위험 → 바이블 "확실하지 않으면 묻는다 / 결정 필요 시 시각화" 적용.
- A의 PoC에는 인게임 미니맵 원본 프레임이 필요한데 현재 자산엔 없음(풀맵·앱스샷·종료화면뿐). 체인 영상 추출 또는 사용자 제공 필요.

## 결정됨 (2026-05-27 사용자)
**"가장 코스트 낮은 순으로 trying, 안 되면 다음도 다 시도."** → 순서 **B → A → C**.
- B(전체맵 화살표)가 최저 코스트 — 전체맵은 이미 zone 검출이 좌표계 확보, 로컬라이제이션 불필요.
- B 불충분(실시간 아님)·실패 시 A(미니맵 템플릿매칭), 그래도 안 되면 C(ML).

## 진행
- B PoC: `.local/poc_player_fullmap.py` — 실제 전체맵 프레임(`.claude/images/배그 맵화면.png`, 3838×2050)에서 측정.
- **결과**: 단순 흰색 임계로는 분리 불가. 흰 컴팩트 블롭 다수가 우측(x>0.85) = UI 메뉴·텍스트, 그 외는 도시 라벨. 노란 마커도 area 8~400 컴포넌트 없음(분산 1058px).
- **결론(B)**: 최저 코스트지만 "임계 한 방"은 아님. 필요: ① 맵 영역 크롭(UI·우측 패널 제외), ② 플레이어 화살표 고유 시그니처(모양/템플릿 매칭), ③ 라벨 프레임 수 장 + 라이브 확인. → 다음 세션에서 라이브 검증 병행해 구현하는 게 효율적(현재 단일 프레임·마커 외형 불확실).
