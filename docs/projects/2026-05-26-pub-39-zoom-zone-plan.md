# PUB-39 — 확대(줌인) 자기장 SIFT-zone

> Linear: PUB-39. 작성 2026-05-26 (v1 배포 후 산출물 보완 + v2 개선). 역할: Claude 구현, Codex 검수.

## 배경 / 문제
사용자가 전체맵을 임의 배율로 확대하면 전체맵 검출이 실패해 자기장이 안 그려진다. 사용자 의도: 확대로 자기장 원이 일부 잘려도 → 원을 인식하고 중심을 잡아 → 미리 정해둔 페이즈 반경에 맞춰 → UI에 전체 원을 표시.

## v1 (배포됨)
`SiftZoneService`: AKAZE 호모그래피로 화면→기준맵(erangel/taego) 매칭 → 흰 호 픽셀을 게임좌표 변환 → RANSAC 원 피팅 → 피팅 반경으로 페이즈 추정. capture.service가 전체맵 검출 실패 시 폴백 호출.

## v1 한계 (Codex 검수)
- 임의 배율 미보장: AKAZE inlier≥15 + 호 점≥30 필요 → 과확대·작은 호에서 null.
- 페이즈를 OCR이 아니라 피팅 반경으로 추정 → 부분 호에서 오추정 가능.
- 흰 픽셀 오염(글자·UI), 단색 지형 호모그래피 실패 (별도 과제).

## v2 목표 (이번)
**OCR 페이즈 힌트 사용.** 현재 페이즈를 OCR 타이머가 이미 알고 있으므로 `detectZone(base64, hintPhase)`로 넘긴다.
- 페이즈→반경 확정 → **호에서 중심만** RANSAC으로 찾는다(반경 고정).
- 중심만 찾으면 되니 필요한 호 점 수가 줄어 작은 호·부분 잘림에 견고.
- hintPhase 없으면 기존 v1(반경 추정) 폴백 유지.

## 비범위 (이번 아님)
- 흰 픽셀 오염 제거(자기장 호만 분리), 단색 지형 대응 → v3.

## 완료 기준
- hintPhase 주면 중심만으로 원 복원, 반경=페이즈 반경, phase=hintPhase 반환.
- 라이브: 적당한 확대에서 자기장 원이 정확한 페이즈 크기로 표시.
- Codex 검수 통과.
