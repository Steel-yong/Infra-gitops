## 2. 분기 결정 (2026-05-18)

사용자에게 4개 옵션 제시:

| | 사용자 작업 | 정확도 | 소요 |
|---|---|---|---|
| A 즉시 자율 | 없음 | ±0.05 | 한 세션 |
| B 어드민 클릭 UI | 5분~1시간 클릭 | ±0.001 | 코딩 1일 + 사용자 |
| C Telemetry API | API Key 발급 5분 | ±0.0001 자동 | 며칠 |
| D 하이브리드 | 단계마다 | 점진 | 점진 |

### 사용자 선택: A

"2번 먼저 진행해봐 그거보고 판단할게" — v1 결과 보고 v1.5(B) 또는 v2(C)로 갈지 결정하겠다는 흐름.

### 자기 피드백

- A는 임시 시드라 결국 교체될 운명 — 시간 낭비 위험.
- 그러나 동작 검증 + 마커 UI 확인이 v1.5/v2 코딩 전에 필수.
- v1으로 동작 확인 후 v1.5/v2가 의미를 가짐.

같은 ±0.02 좌표에 여러 위치가 박히는 경우(예: E4의 학교+로족언덕):
