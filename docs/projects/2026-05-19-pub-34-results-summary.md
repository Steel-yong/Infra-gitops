## 핵심 알고리즘 검증

| 단계 | 알고리즘 | 검증 결과 |
|---|---|---|
| 다운로드 | yt-dlp format 134 (360p video-only) | 360p 130MB / 720p 1.1GB / 1080p 2.6GB |
| 프레임 추출 | ffmpeg `fps=1/30` (30초 간격) | 570 프레임 |
| 인트로 분류 | 좌측 가장자리 G 채널 < 25 | 6 매치 자동 식별 |
| 자기장 검출 | Hough Circle + 흰 마스킹 (minRadius 15%) | **100%** 검출 |
| 마커 추출 | HSV 채도 > 100 + DBSCAN (eps=8) | 평균 14개/프레임 (16팀에서 감소) |
| 격자 OCR | easyocr 영문 (1080p + 2x + CLAHE) | A B D H + J K M N 추출 |
| 변환식 | 선형 회귀 (px → PUBG 좌표) | **오차 0.0002** |
| 클러스터링 | DBSCAN (eps=0.025) | 매치별 8~17 클러스터 |

| 좌측 I J K L M N O P | 1 2 3 4 5 6 7 8 (오프셋 +9, 사용자 명시) |

## 변환식

```python
def transform(px, py):
    return 1.0657 * px + 0.0475, 1.0000 * py + 0.0416
```
