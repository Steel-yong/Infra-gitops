## 1. 자기장 좌표 정규화 기준 (PUB-29, PR #76)

**결정:** 캡처 전체 화면이 아닌 PUBG 맵 영역(정사각형) 기준으로 정규화.

**이유:**
- 기존 코드는 1920×1080 전체 기준이라 Leaflet 맵(1:1 정사각형)에 그릴 때 비율 안 맞음.
- PUBG 전체맵 화면은 화면 높이만큼의 정사각형이 중앙에 표시됨 (1080×1080 등).

**구현:**
- `MapDetectionService.detectMapArea()` 신설: 청록 픽셀 bounding box → 정사각형 정렬.
- 검증 실패 시 폴백: "화면 높이 정사각형이 중앙" 가정.
- `CircleService.extractCircle(base64, mapArea)`로 시그니처 변경.

## 2. 자기장 크기는 페이즈 데이터로 (이미지 측정 X)

**결정:** 페이즈별 자기장 반경은 PUBG 공식 게임 데이터로 하드코딩.

**이유:**
- 이미지에서 자동 측정 시도했으나 게임 배경의 청록 노이즈로 맵 영역 검출 실패.
- 공식 데이터(에란겔 1페이즈 1500m → 비율 0.1875)가 훨씬 신뢰성 높음.

**To-do:**

## 3. 페이즈 자동 감지 방식

**결정 보류.** 다음 옵션 중 선택 필요:

| 옵션 | 정확도 | 구현 복잡도 |
|------|------|----------|
| OCR 타이머 + waitSeconds/shrinkSeconds 매칭 | 80% | 중 |
| 게임 시작 버튼 + 누적 시간 | 95% | 낮음 |
| 자동 검출 (이미지 분석) | 70% | 높음 |

**현재 사용자 의견:** 게임 중 어떤 버튼도 누르고 싶지 않다. 자동이어야 함.

**다음 단계:** OCR 타이머 동작 검증 먼저 (PUB-30 작업). OCR이 신뢰성 있게 작동하면 안 1번 채택.

## 4. OCR 타이머 검증 우선 (이번 작업)

**결정:** Tesseract.js 통합 + 디버깅용 타이머 패널 신설.

**이유:**
- 사용자가 "OCR이 인식되는지조차 모르겠다"고 함.
- 알림 자동화 전에 OCR 동작 확인이 선행되어야 함.

**구현 범위:**
- `useOcrTimer` 훅: 1초 간격으로 비디오 프레임 캡처 → 타이머 영역 크롭 → Tesseract.js OCR.
- `TimerPanel` 컴포넌트: 인식 텍스트 + 잔여 초 + 크롭 이미지 미리보기 표시.
- 알림 통합은 OCR 검증 후 진행.

**제약:**
- Tesseract.js는 CDN에서 로딩 (개발 단계 OK, 프로덕션은 로컬 호스팅 필요).
- 해상도별 타이머 좌표 하드코딩 (1920×1080, 2560×1440, 3840×2160).
