📊 디자인 일관성 평가

측면 평가 대처
색 코딩 (green/yellow/red threshold) 🟢 일관됨 — Grafana 기본 threshold가 9.x부터 통일 불필요
레이아웃 패턴 (헤더 stat + 시계열 + 테이블) 🟢 다운받은 거도 비슷한 패턴 불필요
패널 폰트/스타일 🟢 grafana 테마가 통일하므로 자동 일관 불필요
패널 밀도 🟡 [04] Nodes는 패널 많고, [10] Prometheus는 적음 — 살짝 들쭉날쭉 감수 (drill-down은 깊은 정보 우선)
한국어 vs 영어 🟡 다 영어. Overview만 한국어로 만들 거면 톤 차이 Overview도 영어로 통일 권장
변수(template variable) 위치 🟢 모두 상단 좌측 통일 불필요

✅ 결론

11개 대시보드의 디자인 일관성은 90% 일관됨. 5초 스캔용 Overview(직접 만듦) + Logs(직접 만듦)만 신경 쓰면 됨. 6개 기존 대시보드는 그대로 사용해도 시각적으로 어색하지 않음. 사용자가 외부에서 받은 이유였던 "디자인 괜찮음"이 내장 대시보드에도 동등하게 적용됨.

❓ 결정 필요 4가지

① 11개 다 OK? "이 대시보드 빼고 싶다 / 추가하고 싶다" 있나? Vault 전용 대시보드 등 추가 후보 있음
② cert-manager 커스텀 "issuer 종류별 stat" 추가하면 staging/prod 즉시 구분. 필요?
③ 언어 통일 기존 6개가 영어니까 Overview/Logs도 영어로 통일 vs 한국어
④ 다운받은 거 ID 확인 argocd / cert-manager / longhorn의 정확한 dashboard ID 알려줄 수 있나? 위 평가는 인기 ID 가정한 거라 다를 수 있음
