6. 사용자 통찰 반영

✓ "시작 대기 시간 (인트로 1시간) 불필요한 부분 자르기"

매치 자동 분리 알고리즘 3단 fallback. 인트로 색 fail 시 자기장 반경 변화 기반 v5로 대체. PWS/QUALIFIERS 영상은 정확히 5~6 매치 분리. PGS 영상은 v5 효과 검증 대기.

✓ "도시 vs 능선/조그만 건물 구분"

DBSCAN eps 변화 실험으로 sweet spot 결정:

  • 0.040 (320m): 18 핫스팟 — 도시 권역 통째
  • 0.025 (200m): 37 핫스팟 — 도시 권역 단위
  • 0.015 (120m): 48 → 99 핫스팟 ★ — 도시 구역/능선/건물군 단위
  • 0.010 (80m): 39 — 단일 건물 (S tier 분산)

PUBG 한 명당 사용권 100~150m가 자연스러움 → 0.015 최적.

9. 한계 (정직히)

  • ⚠️ 좌표가 진짜 PUBG 명당인지 시각 검증 안 됨 — 사용자 게임 지식 필요. 화면공유로 자기장 락 후 우측 추천 표시 확인 후 평가.
