에란겔 / 태이고 공식 맵 이미지 확보

결정 완료

공식 PUBG 이미지를 가져온다. pubg.com 또는 pubg.wiki.gg에서 격자 포함 전체맵 이미지 확보. 최소 1024x1024px 정사각형 JPEG.

Leaflet 바인딩 방식

CRS.Simple 설정
bounds = [[0,0],[1,1]]
이미지 좌상단 = (0,0) / 우하단 = (1,1)
모든 마커/원 좌표도 이 범위 내
검증 기준
Pochinki는 D4~E5 사이 (coordX≈0.44, coordY≈0.49)에 표시되어야 함.

소스 우선순위

1
pubg.com/en/game-info/maps/ 공식 페이지 — 격자가 포함된 전체맵 이미지

3
게임 내 M키 스크린샷 직접 캡처 — 격자 오버레이 별도 작업 필요

좌표계

PUBG 그리드 → 0-1 정규화 변환

API 좌표 → 0-1 공식

coordX = X_cm / 816,000
coordY = Y_cm / 816,000
출처: documentation.pubg.com API 좌표 범위 0~816,000 확인
그리드 8×8 = 각 셀 102,000cm / 서쪽=0 동쪽=1 / 북쪽=0 남쪽=1

프로 위치 좌표 시드 — 왜 도시명이 부족한가

핵심 인사이트

에란겔 "Pochinki" = 약 500x600m 범위 안에 수십 개 건물. 프로들이 실제로 쓰는 건 "Pochinki 북쪽 Triple" 또는 "Pochinki 동쪽 능선". 자기장 반경 r=0.05 수준에서는 도시 내 50m 차이가 생사를 가름. 시드 단위: 능선·컴파운드·고지.

v1 수록 포지션 카테고리 (에란겔 기준)

  • 🏙
    랜드마크 중심 — 8개 A등급 게임 내 이름이 표시되는 지역 중심 좌표.
    Pochinki, School, Military Base, Georgopol, Rozhok, Yasnaya, Mylta Power, Prison
  • ⛰
    능선·고지 — 10개 S등급 지형 고점. 자기장 엄폐·시야 확보 우수.
    Pochinki 북능선, School 동능선, Rozhok 남서 고지, 중앙 E4 고지 등
  • 🏠
    격리 컴파운드 — 7개 A등급 도시 외곽 2~4개 건물 집합. 방어·엄폐 유리.
    Farm North/South, 중부 고립 컴파운드 5곳
  • 🌊
    수계 인접 고지 — 5개 B등급 호수·강 주변 산등성이. 시야 확보 + 자연 장벽.
    대형 호수 서안, 강 상류 고지, Sosnovka 섬 포지션
