📦 GitOps 박는 방법

kube-prometheus-stack의 grafana sidecar 자동 import 활용

  1. 이 대시보드 JSON을 components/monitoring/dashboards/onprem-dev-overview.json에 저장
  2. ConfigMap 매니페스트로 wrap, label grafana_dashboard: "1" 부여
  3. kube-prometheus-stack values에 이미 sidecar가 활성화돼 있으면 grafana pod이 자동 import
  4. 다운받았던 6개 대시보드도 같은 방식으로 ConfigMap 박기 → UI import 의존 제거

즉, UI에서 import → ConfigMap에 박힌 GitOps 자동 import로 패턴 통일.
