좌표 정밀도 3단계 로드맵

v1 — 격자 셀 추정

정밀도 0.125 · 공수 2h · 즉시 가능

이 보고서 데이터가 v1. 그리드 A~H × 1~8 셀 중심값을 x=(열×2-1)/16 공식으로 산출.

  • 장점: 출처만 있으면 즉시 시드 가능
  • 단점: 셀 내 50m 단위 차이를 표현 못 함
  • 용도: 서비스 기본 기능 검증 (D4)

v1.5 — pubgmap.io 추출

정밀도 ~0.001 · 공수 4~8h · JS 번들 분석 필요

pubgmap.io는 Leaflet 기반. 마커 좌표가 JS chunk 내부에 번들링됨. Chrome DevTools → Network → JS 필터로 추출.

  • 추출: Leaflet pixel ÷ 맵 이미지 픽셀 크기
  • 주의: TOS 확인 필요
  • 마우스 클릭 콘솔 출력에 lat/lng 패턴 노출 가능성

v2 — Telemetry API ★

정밀도 ~0.001 (실측) · 공수 1~2일 · 완전 자동

유일한 표준 경로. PUBG 공식 API에서 LogPlayerPosition의 x, y (cm) ÷ 816,000으로 우리 좌표계와 그대로 매칭.

  • API Key: 무료 (developer.pubg.com)
  • 텔레메트리 다운로드: API Key 불필요
  • 샘플 매치 200개 → 착지 히트맵 → 클러스터 centroid 60개 자동 추출

Telemetry API 핵심 흐름

// 1. 매치 ID 얻기 (API Key 필요)
GET https://api.pubg.com/shards/pc-na/samples
  Authorization: Bearer <API_KEY>

// 2. 매치 → 텔레메트리 URL 추출
GET https://api.pubg.com/shards/pc-na/matches/{match-id}
  → response.included[].attributes.URL  (asset type = telemetry)

// 3. 텔레메트리 JSON 다운로드 (API Key 불필요, gzip)
GET https://telemetry-cdn.pubg.com/...telemetry.json

// 4. LogPlayerPosition 파싱 → 정규화
{
  "_T": "LogPlayerPosition",
  "character": { "location": { "x": 428000, "y": 302000, "z": 100 } },
  "elapsedTime": 10.0
}
→ coordX = 428000 / 816000 = 0.524
→ coordY = 302000 / 816000 = 0.370

데이터 신뢰도 노트

  • 모든 x/y 좌표는 추정값. 공개 소스 중 0~1 정규화 좌표 직접 제공처 없음.
  • 일부 PUBG Mobile 가이드 포함. 맵 레이아웃은 PC와 동일하나 메타 차이 가능.
  • 능선·소형 컴파운드 명칭은 한국 커뮤니티 콜아웃 용어. 영어권 공개 가이드에는 거의 없음 — 스트리머 클립/VOD 분석이 더 정확.
  • 한국 프로 데이터 부재. Gen.G·Danawa 해체로 최신 한국 프로 메타는 PWS VOD에서만 추출 가능.
