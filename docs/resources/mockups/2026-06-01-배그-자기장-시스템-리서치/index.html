2. 자기장 Center 선택 알고리즘

핵심 규칙

  • Phase 1 center = 맵 전체 임의 (바다 제외)
  • Phase 2+ = 다음 흰 원 center가 현재 blue zone 안 필수
  • 단 새 원 + 반경이 현재 원 살짝 밖에 닿을 수 있음 (edge 가능)

Bias 파라미터

  • 내부 bias 파라미터 (0~10, 커스텀 노출)
  • bias = 0 완전 random
  • bias = 10 정확히 이전 center
  • 기본은 약한 center bias (중심부 ~60%)

실전 prediction 단서

  • Airdrop center가 다음 safe zone과 자주 일치 (특히 후반 phase) — 70%
  • 중심부 60% / 가장자리 30% / 고도 10%
  • 바다·수영장에는 잘 안 끝남
우리 작업 영향 · 우리 label generator는 "다음 자기장이 이전 자기장 안" 가정 가능. 단 edge 닿는 경우 reject 안 함.

4. e스포츠 대회 규칙

2023+ 모든 PUBG Esports 대회 (PGS, PGC, PWS) zone setting = Ranked Match 동일.
즉 1부의 phase 표가 e스포츠 broadcast에 그대로 적용됨.
  • SUPER 룰셋 (Standard and Universal PUBG Esports Ruleset) v5.0.1 — 모든 큰 대회 적용
  • 핵심은 cheating · 장비 · 컨디션 · 룰 — zone은 게임 자체 메커닉 그대로
  • broadcast는 observer 시점 (M-view, F1~F4 follow 등) 자주 전환

6. 우리 작업과 직접 연결

강한 prior

자기장 흰 원 ratio = phase별 미리 알 수 있는 값

ML scale 추정의 hard sanity check 가능 · 흰 원 0.499 + ML scale 1.0 → 일치 · 흰 원 0.165 + ML scale 3.0 → 일치 (phase 3, 3배 zoom).

→ propagate_label.py에 자기장 ring radius prior 검증 gate 추가 가능.

시간 동기화

e스포츠 = ranked 동일 timing이므로 게임 시작 후 누적 시간으로 phase 자동 인덱싱 가능.

예 · 게임 시작 + 120 + 270 = 390초 시점 = phase 2 시작.

reseed 대안

SIFT가 zoom frame에서 실패해도 자기장 흰 원 + phase prior로 시드 가능.

  • 흰 원 ratio → phase 인식
  • 흰 원 center → cropped center 대비 (gx, gy)
  • 도시명 OCR로 1점 매칭 + scale prior로 transform

cropped 영역

영상 1280×720 → cropped 정사각 720×720 (관전 UI 영역 제외).

detect_map_bbox 청록 영역의 largest CC 사용. 정확 ✅
