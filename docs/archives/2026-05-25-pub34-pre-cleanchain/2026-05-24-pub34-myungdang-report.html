어떻게 만들었나 — 파이프라인

[1] PUBG Esports 대회 영상 2개 다운로드 (총 535분) ↓ [2] 30초 간격 1070 frame 자동 추출 ↓ [3] 각 frame "에란겔 매치 진행 중?" 자동 분류 (HSV 색조 분석) ↓ (143 frame 통과) [4] SIFT keypoint 매칭 → 우리 베이스맵과 homography 변환 ↓ (23 frame 매칭 성공, reprojection error 1.6m) [5] YOLOv11 추론 — player marker / name_box / vehicle / airplane 검출 (학습 데이터: 합성 5000장. 사용자 라벨링 0건) ↓ [6] 박스 픽셀 좌표 → 게임 좌표 (gx, gy) 변환 ↓ [7] 색 분류 (6 팀 색 + gray) + 가장 가까운 27도시 매핑 ↓ [8] DBSCAN 클러스터링 (eps=100m, min_samples=5) ↓ [9] 마커 수 기반 S/A/B/C 등급 분류 → 명당 좌표 확정

왜 합성 데이터로 학습했나

실제 영상 frame에는 "정답(박스 좌표)"이 없어서 그대로는 학습 불가. 사람이 손으로 박스 5000장 그리면 약 300시간 노동. 비현실적.

대신 우리가 코드로 가짜 marker를 그릴 때 좌표를 알고 있으므로 정답 자동 생성. 사용자 라벨링 0건으로 학습 시작 가능. 합성이 실제와 충분히 비슷하면 모델은 차이 모르고 학습 → 실제 영상 적용 시 작동.
