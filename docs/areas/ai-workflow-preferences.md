# AI 워크플로우 의사결정

이 프로젝트에서 Claude Code와 Compound Engineering을 사용할 때의 확정된 의사결정 목록.

---

## /ce-compound 세션 히스토리 검색

**결정: 기본값 = 아니요**

`/ce-compound` 실행 시 "Claude Code 세션 히스토리를 같이 검색할까요?" 질문에 **항상 아니요**로 답한다.

**이유:**
- 현재 대화 컨텍스트에 이미 코드/diff/커밋 정보가 충분히 있다.
- 세션 히스토리 검색은 시간 + 토큰을 추가로 소모하며 실질적인 추가 가치가 적다.
- 세션 히스토리 에이전트는 Bash 권한 없이 작동하지 않아 차단되는 경우가 많다.

---

## 새 기능/개선 시 시각화 먼저

**결정: 말로만 설명하지 말고 HTML 목업으로 시각화**

새 기능이나 UI 개선을 제안할 때 텍스트 설명만 하지 않는다.
반드시 `docs/mockups/` 에 HTML 파일을 만들어 시각적으로 보여준 뒤 구현을 시작한다.

**형식:**
- 파일: `docs/mockups/[날짜]-[기능명].html`
- 자급자족 단일 HTML 파일 (CSS 인라인, 외부 의존성 없음)
- 실제 데이터/색상/레이아웃 최대한 반영

---

## /ce-compound 실행 모드

**결정: Full 모드, Lightweight 아님**

`/ce-compound` 선택 시 항상 **Full 모드**를 선택한다.

**이유:** 교차 참조, 중복 감지, 전문 리뷰까지 포함되어야 복리형 지식 축적의 의미가 있다.
