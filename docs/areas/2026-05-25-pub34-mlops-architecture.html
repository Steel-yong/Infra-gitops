2026-05-25 · 지금(로컬 수동) → MLOps(인프라 자동) 전환 그림 · 인프라 학습용

지금 vs MLOps — 한눈에

🖥️ 지금 (로컬 연구 단계)

  • WSL 로컬 /tmp/pub34/yolo/
  • python3 full_pipeline.py 수동 실행
  • 학습: 로컬 GPU 한 번 → best.pt 파일
  • 영상 분석: chain.sh bash 루프
  • 결과: 로컬 JSON 파일
  • 모니터링: 사람이 직접 png 확인

→ 빠르고 간단. 일회성 실험엔 충분. 자동화·재현성·협업은 약함.

☸️ MLOps (인프라 단계)

  • K8s 클러스터 위에서 모든 단계 자동
  • 학습/분석 = K8s Job (GPU 노드)
  • 모델 = Harbor에 버전별 보관
  • 배포 = ArgoCD GitOps 자동
  • 결과 = PostgreSQL + 객체스토리지
  • 모니터링 = Grafana 대시보드

→ 자동·재현가능·협업·재학습. 데이터 쌓일수록 진가.

MLOps 파이프라인 6단계 (우리 인프라 매핑)

1

데이터 (Data)

합성 데이터 생성(synth_gen.py) + 영상 수집(yt-dlp). 데이터셋을 버전으로 관리해 "어떤 데이터로 학습했는지" 추적.
Longhorn (PVC)DVC (신규)Vault (쿠키·키)
↓
2

학습 (Training)

GPU 노드에서 YOLO fine-tune을 K8s Job으로 실행. 하이퍼파라미터·정확도(mAP)를 실험마다 자동 기록 → 어떤 설정이 좋았는지 비교.
K8s Job (GPU)MLflow / W&B (실험추적)
↓
3

모델 레지스트리 (Registry)

best.pt를 버전(v7, v8...)으로 보관. "이 모델은 이 데이터로, 이 정확도" 메타데이터와 함께. 롤백 가능.
Harbor (OCI artifact)MLflow Registry
↓
4

배포 / 서빙 (Serving)

best.pt를 추론 API로 띄움. 영상 프레임 보내면 마커 좌표 반환. capture-service가 이걸 호출해 실시간 분석.
ArgoCD (GitOps 배포)KServe / NestJS+ONNXEnvoy Gateway
↓
5

모니터링 (Monitoring)

검출률·정확도·추론 지연을 실시간 추적. 영상 스타일 바뀌어 정확도 떨어지면(=drift) 알림.
Grafana + Prometheus
↓ (drift 감지 시)
6

재학습 (Retraining)

새 영상/데이터가 쌓이거나 정확도 하락 시 ①~③을 자동 재실행. 사람 개입 없이 모델이 스스로 갱신.
Argo Workflows / Kubeflow Pipelines

너희 인프라는 이미 MLOps 기반을 갖췄다

MLOps 요소이미 있음추가 필요
모델/이미지 저장✅ Harbor—
배포 자동화✅ ArgoCD (GitOps)—
실행 환경✅ K8s (Master+Worker2)GPU 노드 라벨링
스토리지✅ Longhorn—
네트워크/게이트웨이✅ Envoy + Cilium—
시크릿✅ Vault + ESO—
모니터링✅ GrafanaML 메트릭 추가
학습 오케스트레이션❌Argo Workflows / Kubeflow
실험 추적❌MLflow / W&B
데이터 버전관리❌DVC

즉 인프라 뼈대는 거의 완성. MLflow(실험추적) + Argo Workflows(파이프라인) + DVC(데이터버전) 3개만 얹으면 PUB-34가 완전한 MLOps 사이클로 돈다.

현실적 전환 순서

  • 지금: 로컬에서 best.pt·명당 데이터 충분히 뽑기 (연구 — 데이터/정확도가 먼저)
  • 1단계: full_pipeline을 도커 이미지로 → Harbor 푸시 → K8s Job으로 배치 분석 (로컬 수동 → 클러스터)
  • 2단계: 학습도 K8s Job + MLflow로 (실험 추적 시작)
  • 3단계: best.pt 서빙(KServe) + capture-service 연동 (실시간 웹서비스)
  • 4단계: Argo Workflows로 데이터→학습→배포 자동 사이클 (완전 MLOps)

핵심 원칙: "모델·데이터가 안정되기 전엔 인프라부터 만들지 않는다." 지금은 검출 정확도(이름박스·고해상도)부터 잡는 게 맞고, MLOps는 그게 검증된 뒤 얹는 거야.
